# 练习数据与版本

`observations.csv` 是从表内官方 URL 手工摘录的少量历史数值，供第 43 章演示版本选择。不是完整宏观数据库，也不是当前最新数据。GDP 的两个发布版本保留在不同行，不能覆盖。网页正文日期优先于 URL 日期。

`release_date` 表示所引发布的日期；`captured_date` 是本练习整理日期。日期精度仅到天，工具将 `--as-of` 视为该日结束，因此不支持发布当日盘中事件研究。今天整理历史资料不证明当时已自行归档，数据修订研究应继续保存原始文件及校验值。

`teaching_cumulative.csv` 全部是假设数据，故与官方观察分文件存放。`comparability_group` 是需要人工核查的可比性标签，不能仅凭名称或日期自动推断。例中 4 月 basis_B 故意与前月不同，演示程序拒绝跨口径相减。

每行唯一键为 series_id + period_start + period_end + release_date。同一天有多次修订时，应升级到带时区的时间戳和发布版本编号，不能强行使用本教学表结构。

引用与更完整来源路线见教材附录。原始发布未被全量再分发；本表只摘录计算所需字段。
