# 02 从美国读数切换到中国口径：累计、同比与可比基数

[上一章：账户地图](01-economic-map.md) · [目录](./) · [下一章：数据生产](03-data-production.md)

> 中国篇重写版 · 2026-09-23。以下金额表均为教学假设，历史发布另列来源。

**前置阅读：**美国篇[02 数字与统计口径](https://fangpings.github.io/us-econ/02-measurement.html)。默认你已会计算同比、环比、季调折年及名义与实际增长。本章研究这些方法在中国数据中何时可用、何时缺少输入。

## 1. 中国发布表中，先寻找四个容易被略掉的词

“累计”“实际”“其中”“可比口径”会改变一整段判断。它们往往出现在表头或附注，而非新闻标题。

| 中国发布常见表达 | 实际含义 | 从美国标题习惯直接迁移的风险 |
| --- | --- | --- |
| 1—N月增长 | 年初以来相对上年同期 | 当成本月增长或最近速度 |
| 增加值实际增长 | 已作相应价格处理 | 再减PPI，重复消除价格 |
| 其中：限额以上 | 总量中的规定范围部分 | 当成全体，或与总量相加 |
| 按可比口径计算 | 本次同比采用可比基数 | 用上年旧新闻总额相除，认定官方算错 |

这不是中国所有数据都只报累计同比。工业、社零及GDP也有适用的季调环比；美国也发布同比和累计数。真正要转换的是具体序列，不能把国家名当作统计标签。[国家统计局：国家数据指标说明](https://data.stats.gov.cn/staticreq.htm?eqid=8342caf1001611ab0000000464568341&m=aboutctryinfo)

## 2. 累计同比还原单月：什么时候可以，什么时候不可以

假设下面来自同一版本、同一范围且可加的销售金额：

| 期间 | 上年累计 | 本年累计 | 累计同比 |
| --- | ---: | ---: | ---: |
| 1—2月 | 200 | 220 | 10% |
| 1—3月 | 300 | 324 | 8% |

3月上年金额为100，本年为104，所以单月同比4%。累计增速下降2个百分点既不是3月下降2%，也不是3月增长8%。

中国月度研究常试图从工业利润、投资等累计资料中提取边际变化，因此这一操作很有用。但有三个关口。

**第一，必须有金额或足够的基期权重。**只知道累计增速10%和8%不能唯一恢复3月。若上年3月规模只有50，同样累计增速对应的单月结果会不同：本年1—3月250×1.08=270，3月50，单月零增长。

**第二，本年两个累计额及相应基数必须来自兼容范围。**普查修订、名单变化或口径调整可能使相邻发布不能直接相减。即使都是“亿元”，也不能跳过这一检查。

**第三，反推所得须标为估算。**若用舍入的累计增速反推基数，得到的是近似值；月份规模较小时，误差会被差分放大。不能把自算结果冠以“官方单月同比”。

实际发布的工业利润和社零附注会提示范围变化对同期数的影响。若没有对应的可比基期金额，应说明不能精确复算，必要时保留累计判断。[2024年工业利润附注](https://www.stats.gov.cn/xxgk/sjfb/zxfb2020/202501/t20250127_1958485.html)；[2024年12月社零附注](https://www.stats.gov.cn/xxgk/sjfb/zxfb2020/202501/t20250117_1958327.html)

## 3. 为什么上年的公开金额不是今年同比的分母

设去年新闻只覆盖A、B两家企业，收入合计200。今年名单包含原先已经营的C：三家今年收入280，按今年范围重建的去年收入250。

```text
跨旧发布直接相除：280/200−1=40%
同范围计算：280/250−1=12%
```

两者差异来自观察范围。把今年报道的12%用来反推，能得到本例可比基数250；真实发布中增速舍入、统计调整和价格处理意味着这种反推未必精确，更不意味着可以推断遗漏企业的真实名单。

这里还要区分新开业与跨门槛。新开业企业去年可能确实没有产出；跨过规模门槛的老企业去年已有产出。研究企业增长时，不能简单删除所有今年新入样单位，也不能把它们全部当作本年新生产。

[第03章](03-data-production.md)会解释中国名录和联网直报怎样形成这个问题。对照美国时，也要读其样本出生死亡估计或基准修订；美国有不同的处理路径，并非样本永远固定。

## 4. 春节与1—2月合并：不是丢失了一个普通月份

国家统计局2025年发布日程说明，2月不发布1月份工业、投资、房地产、社零及工业效益等指定数据。不能据此推断CPI、PMI或所有金融数据也按同样方式合并。[2025年统计发布日程及说明](https://www.stats.gov.cn/xw/tjxw/tzgg/202412/t20241230_1957931.html)

假设工厂只是春节停工日期移动：去年1月80、2月120，今年1月120、2月80。单月同比是+50%与−33.33%，两月合计零增长。先看合并窗口可以减轻错位影响。

为什么合并后还可能受影响？备货可能前移到12月，复工可能延到3月；工作日和假期期间的服务消费也与工业生产不同。用一个统一的“春节修正系数”调整所有行业，没有可靠依据。

比较中美最近动能时，应选同样窗口并注明季调。美国的某个月季调环比，与中国1—2月累计同比，不能仅靠把后者除以2变成同一对象。美国篇的换算公式需要完整路径；没有路径就不能完成转换。

## 5. 把中国季度同比与美国季度折年拆开

中国2024年四季度GDP初步发布包含当季同比5.4%及全年5.0%；相关解读给出季调环比1.6%。美国2024年四季度第三次估计的实际GDP季调环比折年增速为2.4%。这几项属于不同时间算子，不能写成“中国5.4%对美国2.4%”。[中国GDP表](https://www.stats.gov.cn/xxgk/sjfb/zxfb2020/202501/t20250118_1958363.html)；[中国环比解读](https://www.stats.gov.cn/sj/sjjd/202501/t20250117_1958345.html)；[BEA第三次估计](https://www.bea.gov/news/2025/gross-domestic-product-4th-quarter-and-year-2024-third-estimate-gdp-industry-and)

只演示时间尺度转换，暂不消除两国版本差异：

```text
中国1.6%的季度环比 → 折年：(1.016⁴−1)×100≈6.56%
美国2.4%的折年 → 季度环比：(1.024^(1/4)−1)×100≈0.595%
```

这使速度表达更接近，但还要统一发布截止时刻、实际量方法与修订版本。中国1.6%是舍入数，自算6.56%不是官方新发布。季度金额也要区分实际季度额与美国常用的季调年率金额，不能把金额年率和增速折年当同一操作。

## 6. 中国金融标题中的“同比少增”是哪一层变化

去年某月新增贷款100，今年新增80，年末余额仍可能继续上升。“少增20”比较的是两个期间增量，既不是贷款余额减少20，也不是企业今年总共获得的所有融资减少20。

若上月余额1,000，本月在无其他调整条件下变成1,080，余额环比增长8%；本月新增80，相对去年同月新增100少20。若不知道去年同月余额，无法计算余额同比。

把“社融增量同比多增”和“社融存量同比增速回落”同时看到，也不必先认定矛盾：增速还受存量基数、其他月份和统计调整影响。跨国比较应将中国融资流量对应美国同期间净交易，而非对应一个资产余额同比。

## 7. 实操：把一组标题改造成可比较数据

教学输入：中国1—3月名义销售324、同比8%，1—2月220、同比10%；中国规上工业实际同比6%；美国某月零售季调环比0.5%；中国贷款本月新增80、同比少增20。

先恢复中国3月销售4%，但注明同范围与同版本假设。然后停止直接排序：美国0.5%还需历史路径转换，中国社零与美国零售也需统一覆盖。工业6%已经是实际量，不能直接减去销售4%得到库存；贷款少增不能写作余额下降。

一份合格简报保留四条不同性质的观察，而不是强行拼成一个“强弱分数”。随后去找适配的价格、范围和月度路径。

## 练习：转换中国发布，而不是复习百分比

1. 同范围累计收入：去年1—2月400、1—3月600，今年440、648。求3月同比，并解释累计增速为什么下降。
2. 只有累计增速10%和8%，为什么不能复原上题？举出一个会改变结果的输入。
3. 本年总额520、官方可比同比4%，上年旧发布总额480。为何不能直接指控两数矛盾？
4. 贷款新增由150降到120，余额由2,000到2,120。分别写出当月增量、同比少增及余额环比；什么仍算不出？
5. 中国季调季度环比1%、美国季调季度折年4%，比较之前应做什么？
6. 打开2025年发布日程，解释为什么系统不能把缺少的1月社零填成零，或把1—2月总额的一半当成官方1月数。
