# 22 中国财政四本预算：收入、支出与赤字怎样对上账

[上一章：资金市场与非银](21-money-markets-nonbanks.md) · [目录](./) · [下一章：地方财政与债务](23-local-government-debt.md)

> 编写于 2026-09-26。真实算例固定使用 2025 年公布的 2024 年预算执行资料；执行报告、预算和决算不得混接。

**前置阅读：**美国篇 [14 财政、国债发行与 TGA](https://fangpings.github.io/us-econ/14-fiscal-policy.html)，中国篇 [05 GDP](05-gdp.md)。预算、融资和现金支付的区别作为已知。本章解释中国为什么要分四本预算，以及为什么新闻里的收支差额往往不等于公布的赤字。

## 1. 四本预算分的是资金性质，不是四个政府

中国预算体系包括一般公共预算、政府性基金预算、国有资本经营预算和社会保险基金预算。每一本又涉及中央与地方等层级。不能把“四本”理解为互不往来的四只现金箱，也不能把“全国”理解为中央财政本级。[《预算法实施条例》](https://app.www.gov.cn/govdata/gov/202008/20/461993/article.html)

| 预算 | 核心收入与用途 | 最容易混淆的对象 |
| --- | --- | --- |
| 一般公共预算 | 税收和相应非税收入，支持公共服务、民生、行政运行等 | 不等于全部政府收入和全部社会保障支出 |
| 政府性基金预算 | 按规定取得的基金收入及相应安排，土地出让收入是地方重要来源 | “基金”不是股票基金；专项债筹资需单列识别 |
| 国有资本经营预算 | 国家作为资本所有者取得的有关收益及其安排 | 不等于国企全部营业收入、资产或利润 |
| 社会保险基金预算 | 相应社会保险缴费、财政补助等与待遇支出 | 不等于一般公共预算里的“社会保障和就业”科目 |

这套分类的意义，是辨认税收公共财力、特定用途资金、所有者收益及保险筹资支付的不同关系。中国有土地使用权出让和广泛的国有资本经营等安排，分析只看税收预算会漏掉重要渠道；但存在多本预算并不意味着可以绕过预算约束任意互相调钱。

一个部门也可能获得不同预算来源。看到“教育支出”或“养老支出”，应继续问：哪本预算、哪一级政府、按功能还是经济性质分类？名称相近的项目未必是同一统计范围。

## 2. 从一笔税款到月度财政数字

企业依法申报纳税，税款按征收和缴库安排进入国库，按税种、预算级次等记录。预算单位按批准安排形成支付，财政按科目汇总执行情况。月度财政收入主要来自执行记录，不是抽样询问企业“感觉今年缴税多不多”。

但执行记录也要解释时点。退税、缓缴后补缴、缴款期限和一次性非税收入，可以改变当期现金收入；企业当期生产或利润不是税款现金入库的唯一决定因素。税收增速低于名义 GDP，不能在没有税制、税基、价格和时点资料时直接判断漏征。

**教学例子：**企业今年形成应纳税额 100，本年现金缴纳 90，另收到以前年度退税 10。相关现金净收入与当期经济形成的税额不会相同。现实应按具体税种和财政统计处理核对，本例只说明“经济发生”与“入库执行”有不同的时钟。

支出也有阶段：预算授权、指标下达、采购或合同、实际支付、资产或服务交付。财政执行支出记录并不自动告诉你最终工程完成了多少。第 24 章将继续桥接。

## 3. 中央对地方转移支付，为什么合并时只能算一次

中国地方承担大量公共服务和支出，地方本级收入与支出规模之间的差额，不能直接当作地方赤字。中央转移支付是重要资金来源，还可能有其他依法调入及结转资金。

**教学预算：**中央本级收入 100，地方本级收入 80。中央本级实际支出 50，另向地方转移支付 50；地方把本级收入与转移收入合计 130 全部用于支出。

| 项目 | 中央视角 | 地方视角 | 全国合并 |
| --- | ---: | ---: | ---: |
| 本级收入 | 100 | 80 | 180 |
| 转移支付 | 支出 50 | 收入 50 | 内部往来抵销 |
| 本级最终支出 | 50 | 130 | 180 |

中央含转移支出的支出 100，加上地方支出 130，得到 230，会把同一笔 50 计算两次。正确合并是中央本级支出 50 加地方支出 130，得到 180。

因此，阅读“地方财政收入”必须确认是地方本级收入，还是加上中央转移支付后的可用收入；阅读“中央财政支出”则要确认是否含转移支付。不同栏目不能凭标题中的中央、地方几个字机械相加。

## 4. 跨预算调入与财政补贴，也需要抵销

国有资本经营预算按安排调出资金支持一般公共预算，一边记调出、一边记调入，不是全国财政从外部又获得两份收入。一般公共预算补贴社会保险基金，同样是政府预算内部的资金连接。

**教学合并：**一般公共预算收到外部收入 100，对公众购买或转移支付 80，另补贴社保基金 20。社保基金收到缴费 50 和财政补贴 20，支付待遇 60，结余 10。

```text
合并外部收入 = 100 + 50 = 150
合并外部支出 = 80 + 60 = 140
合并结余 = 10
```

若直接加两本预算收入，得到 170；直接加支出，得到 160，两边都重复了内部 20。差额碰巧仍为 10，不代表这种加总可以用于比较政府规模或计算支出乘数。

四本预算全部合并还涉及更多内部往来、不同的余额和融资安排。没有完整抵销表时，可以分别展示，并清楚注明范围；不要将简单四项之和命名为精确的“政府总支出”。

政府性基金和国有资本经营预算中的某项结余，也不是研究者可自行划为自由支配现金的金额。资金是否可调、能调多少、走什么程序，要查当期预算安排与规则。

## 5. 最关键的算例：2024 年收支差额为什么不是预算赤字

财政部 2025 年 3 月公布的执行报告，提供了完整的一般公共预算平衡关系。以下单位均为亿元，使用该报告当时版本。[财政部：2024 年预算执行与 2025 年预算草案报告](https://www.mof.gov.cn/zhengwuxinxi/caizhengxinwen/202503/t20250314_3959885.htm)

| 平衡项目 | 金额 |
| --- | ---: |
| 一般公共预算收入 | 219702.12 |
| 调入资金及使用结转结余 | 25410.50 |
| 收入总量 | 245112.62 |
| 一般公共预算支出 | 284612.25 |
| 补充中央预算稳定调节基金 | 1100.37 |
| 支出总量 | 285712.62 |
| 收支总量差额，即报告赤字 | 40600.00 |

逐步计算：

```text
新闻常用收支差额 = 284612.25 − 219702.12 = 64910.13
报告预算赤字 = 64910.13 + 1100.37 − 25410.50 = 40600
```

两个差额不一样，原因在平衡项目，不是加减法失效。这里“收入总量”包含调入及使用以前形成的资金，不代表当年又征收了这些税；补充稳定调节基金也不等于购买当期商品服务。

反过来，报告赤字也不能直接等同财政对当年需求的全部影响。政府性基金等其他预算、以前年度融资本年使用，以及支出类型，都可能改变需求而不按同样方式进入这个一般公共预算赤字。

若要计算赤字率，还要说明使用预算安排中的 GDP 口径，还是后来修订的实际 GDP。用不同版本分母，结果可以与年初政策目标有差异；这种差异不能直接叫“超预算”。

## 6. 土地收入和国企收益：两种不同的政府收入角色

土地使用权出让收入主要在地方政府性基金预算中观察，其形成与土地交易、合同和缴款进度相关。它是毛收入，相关支出还包含征地、拆迁、土地开发等，不能把全部出让收入当作可用于其他公共服务的利润。[财政部：土地收入管理的历史制度说明](https://www.mof.gov.cn/zhuantihuigu/czjbqk2011/czsr2011/201208/t20120831_679821.htm)

国有资本经营预算则需要区分企业与政府股东。国企营业收入先支付生产经营成本，形成利润；按相应规则取得的所有者收益，才进入有关预算。将国企销售收入直接加到财政收入，会混淆市场交易与政府取得的收益。

**教学例子：**国企营业收入 1,000，成本费用及税费等合计 900，形成净利润 100；题设按适用安排上缴 30。财政不能因为控制该企业，就把营业收入 1,000 全记为当年预算可用财力。实际还需区分上缴依据、利润所属年度和现金到账时点。

国家作为征税者、土地权利出让者和资本所有者，分别获得不同性质的收入。这些角色是理解中国财政的重要内容，但不意味着各项收入都可互相替换。

## 7. 与美国比较：不能把中国一般公共预算对着全部美国政府

美国联邦预算也有不同基金和信托账户，其汇总要处理内部往来。财政部月度报告明确区分预算收入、抵销收入和政府内部交易；并非美国只有一张没有内部结构的现金表。[美国财政部：2024 年 12 月月度财政报告及说明](https://fiscaldata.treasury.gov/static-data/published-reports/mts/MonthlyTreasuryStatement_202412.pdf)

| 比较问题 | 中国需要选的范围 | 美国需要选的范围 |
| --- | --- | --- |
| 中央政府预算压力 | 中央相应预算及平衡项目 | 联邦预算及基金合并口径 |
| 全国政府规模 | 中央与地方、跨预算抵销后的相关范围 | 联邦、州和地方的相应合并范围 |
| 当期新增需求 | 消费、资本形成、转移与融资分别桥接 | 国民账户政府购买及其他收入转移 |
| 社会保障 | 社保基金及相关财政补贴关系 | 对应保险项目、信托账户和预算范围 |

中国自然年度和美国联邦财政年度也不同。比“2024 年财政收入”前，要确认期间是否一致。更深一层，预算账户不等于国民账户政府部门；政府经营企业、转移支付和资产交易都需要转换。

合格比较可以很窄：先比较两国中央层级、同一自然年度、相似收入支出范围，再列出未匹配项。错误比较则是拿中国一项赤字率与美国另一个政府层级的广义借款比率，直接评价谁更积极。

## 8. 官方资料带读：月报、执行报告、决算依次使用

先打开[2024 年财政收支月度汇总](https://bgt.mof.gov.cn/zhuantilanmu/rdwyh/ysbgjyszx/202501/t20250124_3955083.htm)，识别一般公共预算和政府性基金预算两组表，记录收入支出的年度累计及分项。

再到第 5 节执行报告补齐调入、结转和稳定调节基金等平衡项目。最后到[2024 年全国财政决算目录](https://yss.mof.gov.cn/2024zyjs/)查对应决算表。决算提供后续核定版本，不能把其中某一行换进早期执行表，却保留其他旧数字。

阅读目标不是只摘一个“支出增长率”，而是留下四个标签：预算种类、政府层级、期间和版本。下一章再用这些标签识别地方债与土地财政。

## 9. 自测与参考答案

1. 中央本级支出 40、对地方转移 60，地方最终支出 160，全国合并支出多少？
2. 一般公共预算收入 100、支出 140，调入及结转 25，补充稳定基金 5，按题设平衡关系赤字多少？
3. 两本预算之间转移 15，为什么直接加总收入和支出即使差额正确仍可能误导？
4. 国企销售额 500、利润 50、上缴收益 10，哪个数能直接作为题设股东预算收入？
5. 地方本级收入小于地方支出，为什么不等于地方预算违法失衡？
6. 将中国一般公共预算支出与美国联邦总支出比较，应先补哪些信息？
