# 中国宏观经济：从经济数字到运行机制——与美国对照理解

本书是[美国宏观经济教材](https://fangpings.github.io/us-econ/)的进阶对照篇，默认读者已经学习美国篇相应章节。每章开头列出具体前置阅读；增加值、增长率、调查权重、现金流和增长核算等共通原理只作必要回顾。

中国篇的主体是：中国的制度与经济行为怎样留下记录，记录怎样形成指标；描述同一个现象，中美为什么使用不同观察对象与统计方法；这些差异会改变哪些判断。

学习主线是：统计与账户入口 → 生产、家庭与企业 → 价格 → 融资与政策 → 财政及开放经济 → 股票市场 → 房地产全链条 → 综合实践。将共通原理用于中国时，要补齐中国的调查范围、核算桥接和制度条件。

中美差异分三类处理：统计定义不同；两国共有机制但结构与重要性不同；具体制度安排不同。每章用中国原表和算例检验这些差异，不将不同名称简单翻译成同一个指标。

### 本模块必须回答的问题

研究主线是：**经济增加值 → 上市公司可取得的利润 → 归属于普通股股东的利润 → 每股现金流与分配 → 买入估值及最终回报**。每一步都要检查范围、股数、治理和价格，不能直接把 GDP 增长率当成股票应有涨幅。

“三千点”首先需要确定指数、起止日期及是否包含分红。上交所另行发布了与上证综指价格指数对应的全收益指数，因此点位比较与股东含分红回报需要分别计算。[上交所：上证综合全收益指数发布说明](https://www.sse.com.cn/market/sseindex/diclosure/c/c_20200918_5221434.shtml)

指数方法与监管制度按历史版本研究。上证综指 2020 年曾调整样本纳入等规则；分红制度也持续修订。不能用今天的规则解释全部历史，更不能把“分红少”“IPO 多”“国企多”预设为不需检验的单一根因。[上交所：2020 年编制方案修订](https://www.sse.com.cn/market/sseindex/diclosure/c/c_20200619_5130635.shtml)；[证监会：2023 年现金分红指引修订](https://www.csrc.gov.cn/csrc/c100028/c7449654/content.shtml)

综合案例将分别计算多个起点的年化价格与全收益回报、每股盈利和估值变化，再做行业结构对齐。新股纳入、退市及成分更换需处理样本变化；增发可能改变每股权益，但不能未经计算就断言新增上市机械压低指数。

## 怎样检验自己是否学会

遇到一个数字，先说清对象、单位、时期和版本，再计算或解释。遇到一个变化，提出至少两种可能机制，说明什么证据能够区分它们。公式成立，不代表因果判断成立；能复述名称，也不代表能读懂原表。

本书沿用 us-econ 的教学深度：中国机制与中美差异由正文承担解释责任，给出必要中间步骤；统计调查、市场定价和行政设定分别讲清形成机制；真实资料用于核查，自编算例用于理解；练习答案同时交代推理和限制。
