# 中国宏观经济：从经济数字到运行机制——与美国对照理解

本书面向有一般大学学习能力、没有经济学专业基础的自学者。前置能力是四则运算和百分比；统计与金融术语在首次使用时解释。

学习主线是：谁在生产和赚钱 → 谁在消费和投资 → 谁向谁融资 → 政府与央行怎样影响这些行为 → 结果怎样体现在增长、就业、物价和资产价格上。

中美比较从共同问题出发：想测量什么，两国分别怎样测量，为什么这样设计，差异会怎样改变判断。不能把相似中文名称当作等价关系，也不能把制度不同当作放弃比较的理由。

## 怎样检验自己是否学会

遇到一个数字，先说清对象、单位、时期和版本，再计算或解释。遇到一个变化，提出至少两种可能机制，说明什么证据能够区分它们。公式成立，不代表因果判断成立；能复述名称，也不代表能读懂原表。

本书沿用 us-econ 的教学要求：正文承担解释责任，给出必要中间步骤；统计调查、市场定价和行政设定分别讲清形成机制；真实资料用于核查，自编算例用于理解；练习答案同时交代推理和限制。
