# 11 中国房地产：预售资金、交付、土地与地方经济

> 中国篇重写版 · 2026-09-23。制度按所引文件说明，具体城市与合同仍需另查；金额及项目算例均为教学假设。

**前置阅读：**美国篇[07 房地产与企业活动](https://fangpings.github.io/us-econ/07-business-and-housing.html)、[19 偿债与信用风险](https://fangpings.github.io/us-econ/19-credit-risk.html)。住房杠杆与利率的一般原理只作调用。本章主线是中国预售如何连接家庭、开发企业、施工和地方财政，以及同名中美指标为何覆盖不同阶段。

## 1. 预售使家庭需求同时成为项目资金来源

先画一条中国项目链：取得土地和前期融资 → 开工 → 达到适用销售条件后签订预售合同 → 购房款进入项目资金链 → 继续建设 → 竣工与交付。法律上的预售条件和资金拨付以所在地及合同适用规则为准，本图只表达阶段关系。

预售的经济作用不只是提前确认需求。购房者在获得完整住房之前支付部分或全部购房款，使家庭资金及按揭贷款可以进入建设期；同时，购房者承担等待交付的风险，开发商承担继续建设与履约责任。

因此需求预期和交付预期可能相互反馈：若家庭担心交付，签约与回款可能减少，项目现金进一步受压；若新增资金与施工能够改善交付可信度，可能减轻这类顾虑。这个机制要查项目进度、合同履约及回款，不能仅由全国销量下降认定所有项目违约。

美国新独栋住房也可以在开工前或建设期出售，Census销售定义允许相应合同或定金时点。因此制度比较应查购房款支付、施工融资和交付安排，而不是以“美国没有预售”作为起点。[Census新房销售定义](https://www.census.gov/construction/soc/definitions.html)

## 2. 一条链上，各指标究竟在观察什么

一个开发项目通常经历取得土地、融资、开工、施工、销售、竣工和交付。预售使销售可以发生在竣工之前；各阶段可以交错，也可能停滞。

| 中国常见指标 | 观察对象 | 最容易误读之处 |
| --- | --- | --- |
| 房地产开发投资 | 报告期开发活动的投资完成额，包含相应土地购置费用等 | 不等于 GDP 中住宅投资，也不等于开发商全部现金付款 |
| 房屋新开工面积 | 报告期新开始施工的房屋建筑面积 | 不等于新增购房需求，也不是新开工套数 |
| 房屋施工面积 | 报告期处于施工范围的房屋面积，含跨期项目 | 不是只在期末仍未完工的面积存量 |
| 房屋竣工面积 | 报告期按规定完成的房屋面积 | 不等于同期已售出、已交付或入住的面积 |
| 新建商品房销售面积、金额 | 报告期合同销售的面积和合同总价款 | 不等于到账款项，也不等于仅住宅 |
| 商品房待售面积 | 期末已竣工、可供销售或出租而尚未售出或出租的面积 | 不能代表所有未售期房、存量住房或空置住房 |
| 房地产开发企业到位资金 | 企业实际可用于开发经营的各类资金来源 | 不等于新增银行贷款；购房款也是资金来源 |

实际报告还区分住宅、办公楼、商业营业用房等。比较时应先统一物业类型，再统一时间、地区和单位。上述口径可逐项对照国家统计局[2024年全国房地产市场基本情况的附注](https://www.stats.gov.cn/sj/zxfb/202501/t20250117_1958328.html)。

“施工面积 = 上期施工面积 + 新开工 − 竣工”通常不能作为官方序列的精确恒等式：施工面积是报告期范围指标，跨年、停复工和报告范围变化也要处理。若要建立项目库存模型，应另行定义“期末在建未竣工面积”，再处理本期转入、退出及调整。

这里要调用美国篇第02章的存量与流量区分：一个名字听起来像存量，不代表统计表就在测量那个期末存量。

## 3. 到位资金、监管资金与集团现金：为什么不是同一笔“可用钱”

2022年三部门关于保函置换预售监管资金的通知要求相应预售购房款进入监管账户，并对银行保函置换、额度及补足等作出安排。这里应理解的制度目的，是在项目交付资金保障与企业资金使用之间设置约束；具体操作仍须依适用规则核查。[三部门通知](https://app.www.gov.cn/govdata/gov/202211/15/494283/article.html)

因此“开发企业到位资金增加”并不等于集团总部自由现金增加同额。部分资金与特定项目及工程用途绑定；集团合并报表、项目公司现金和可跨项目调拨现金，也可能不同。

教学假设某项目收到购房款100，其中本题规则要求70继续用于该项目交付，其他条件下可调配30。若集团有到期债务50，不能用账上100直接断言偿债无压力。反过来，集团资金紧张也不等于受保护项目已没有任何施工资金。70/30只是教学约束，不代表全国实际统一可调拨比例。

进一步设本期获准支付工程款40、实际形成工程50，施工企业仍可能新增应收10。资金监管解决用途约束的一部分，并不保证工程、付款与交付完全同步。

这解释了为什么研究房企要同时看销售合同、资金到账、监管与受限现金、债务到期以及项目进度。将一项金额称为“资金面改善”，需要说清改善的是哪一层。

## 4. 为什么这条链会反向影响自己

先考虑一条条件性机制：

```text
购房意愿减弱
→ 合同销售和回款减少
→ 若其他融资不足，开发商可用现金下降
→ 新开工、施工付款或拿地可能减少
→ 建筑及相关行业收入承压
→ 就业、购房能力和交付信心进一步变化
```

每个箭头都需要条件。企业可能拥有充足现金；融资可能补位；政策或项目安排可能优先保障既有项目完工。因此，**新开工下降与竣工上升可以同时发生**：开发商收缩未来项目，同时把资金集中到过去已售的住房。

时间差还意味着，销售短期改善未必立刻带来投资改善。企业可能先还债、补足旧项目资金，或观察需求是否持续，再决定新项目。反过来，大量旧项目在建，也能使投资在销售转弱后继续维持一段时间。

住房还连接装修、家电、家具和中介，但不能把这些行业的所有营业额都算成房地产“贡献”。估计产业关联需要扣除中间投入并识别实际由住房活动带动的部分，否则会重复计算。

## 5. 土地把开发企业与地方财政连起来，但土地收入不是全部财力

开发企业拿地影响土地交易，地方政府国有土地使用权出让收入则是政府性基金预算中的一项收入。房地产销售改善可能提高企业补充土地储备的意愿，但也可能先用于还债或旧项目，因此销售到拿地的联系有条件、有时差。

财政部2025年1月发布的2024年财政收支资料列示，国有土地使用权出让收入48,699亿元、下降16%，所属的是地方政府性基金预算收入口径。[财政部：2024年财政收支](https://bgt.mof.gov.cn/zhuantilanmu/rdwyh/ysbgjyszx/202501/t20250124_3955083.htm)

读这个数有三道边界。第一，它不是一般公共预算全部收入；第二，不等于当年土地成交合同总价，收缴时点与交易时点要分别查；第三，收入总额不等于扣除征拆等相关支出后可用于任意项目的净财力。

所以土地收入下降不意味着地方所有支出同幅减少：其他收入、转移支付、债券和支出排序都可能影响结果。但它可以形成具体压力路径：相应资金来源下降 → 部分项目拨付或配套资金受限 → 施工与供应商回款变化。要验证，应查对应预算收支和工程执行，而非只把土地收入同比乘一个固定GDP系数。

中美地方财政与住房的连接也不能只比“土地财政”一个词。美国对应研究还涉及地方税收及预算等不同接口；中国这里先把出让收入这一具体制度讲清，跨国比较时再分别核对税种、交易收入、债务与支出责任。

## 6. 数字是怎样形成的：开发企业报表与成交价格

开发活动数据以房地产开发经营企业的项目及经营资料为基础，汇总项目进度、销售合同、资金来源等。理解这套报表，需要回到企业与项目：一栋房本期有没有开工，形成多少工程量，合同是否签订，资金是否实际到位。它不是简单把网上挂牌房源加总。

价格统计又是一套工作。国家统计局70个大中城市住宅销售价格发布区分新建商品住宅和二手住宅，并分面积类别；新建住宅使用当地房地产管理部门网签数据，二手住宅结合相关调查资料。分类、汇总和可比处理用于减少直接平均造成的偏差，但价格指数仍受覆盖和方法限制。参见[2024年12月份70城住宅价格报告及附注](https://www.stats.gov.cn/sj/zxfb/202501/t20250117_1958323.html)。

为什么不能用销售额除以面积替代房价指数？看一个所有单价都没有变化的市场：

| 住房类型 | 单价，万元/平方米 | 上期成交面积 | 本期成交面积 |
| --- | ---: | ---: | ---: |
| 普通住房 | 1 | 50 | 80 |
| 高价住房 | 3 | 50 | 20 |
| 合计 | — | 100 | 100 |

上期平均成交价为 `(50×1+50×3)/100=2` 万元/平方米；本期为 `(80×1+20×3)/100=1.4` 万元/平方米，下降30%。两类住房的单价均未下跌，变化完全来自成交结构。

即使同一城市的同一面积段，地段、楼龄和装修也可能变化。因此分类价格指数通常比未经调整的总均价更适合研究价格变化，但也不能假定它完美测量了每一套房的升跌。

70城数据还不是全国所有城乡住宅价格的全覆盖统计。简单平均70个城市的涨跌幅，得到的是你自定权重的指标，应明确命名和用途。

## 7. 同一住房周期，中美为什么选择不同观察窗口

| 共同问题 | 中国常见观察 | 美国常见观察 | 比较前要处理的差异 |
| --- | --- | --- | --- |
| 未来建设意向 | 拿地、项目计划、新开工 | Building Permits，建筑许可 | 批准不等于开工；统计对象和单位不同 |
| 实际进入建设 | 新开工面积 | Housing Starts | 面积与住房套数不同；单户、多户结构不同 |
| 已建成多少 | 竣工面积 | Housing Completions | 面积和套数不能直接比较水平 |
| 新房需求 | 新建商品房合同销售 | New Home Sales | 美国该销售系列主要是新建独栋、为出售而建的住房 |
| 可售库存 | 商品房待售面积 | New Homes for Sale | 中国待售的竣工边界与美国新房待售库存不同 |
| 同类房价格 | 分城市、类别的住宅价格指数 | FHFA House Price Index等 | 采样、融资覆盖及价格调整方法不同 |

美国 Census 的新房销售也可以在开工之前或施工期间发生。不能把中美差异概括成“中国预售、美国一律现房”。美国新房销售调查主要覆盖为出售而建的新独栋住房，而开工统计包括更广的私人住宅建设；出租公寓开工不能机械对应这份新房销售量。美国待售新房可以包含尚未开工或仍在施工的住房，因此它与中国“竣工未售”的待售面积不是同一个库存边界。参见 Census 的[调查定义](https://www.census.gov/construction/soc/definitions.html)和[开工、销售系列的范围比较](https://www.census.gov/construction/pdf/soc_nrc_vs_nrs.pdf)。

这种差异有两层来源。首先是统计单位和调查设计：项目面积、住房套数、许可样本、合同记录各有用途。其次是住房建设类型与融资安排：一个经济体里多户开发、独栋建设、出租建设、项目融资各占多少，会改变哪些指标最有解释力。判断具体时期的差异，需要另外查相应结构数据。

美国 FHFA 的常用房价指数采用重复交易方法，通过同一物业在不同时点的交易减轻住房组合变化影响；不同系列覆盖不同融资样本。例如只购买交易的系列与包含再融资估值的系列不能混用。这也不意味着样本覆盖所有住宅或消除了房屋翻修等所有影响。参见[FHFA HPI说明](https://www.fhfa.gov/data/hpi)及[常见问题](https://www.fhfa.gov/faqs/hpi)。

## 8. 存量住房、期房和待售：库存位置决定政策含义

中国商品房待售面积主要观察竣工后符合条件却未售出的商品房。若项目尚未建成但未售，或住房早已售出却无人入住，不属于同一个待售概念。美国新房待售库存又可以包括未开工或在建的新独栋住房，因此“去化月数”必须先统一边界。

设城市有竣工未售20万平方米、在建未售30万平方米、已售未交付40万平方米。中国待售式窗口看到的是第一部分；未来可售供应还需第二部分；交付责任主要与第三部分相连。把三者都叫库存，会混淆促销售、补工程资金和保障履约三种不同任务。

全国平均又可能掩盖城市和地段差异。某城库存高，另一城可售房稀缺，全国总面积不能直接推导两地价格压力。应按城市、物业类别、项目阶段和可实现销售速度研究，不能仅用总面积除全国销售额。

利率传导也要分群体：新购房者的融资条件、存量借款人的重定价、开发企业融资并非同一条利率。美国篇固定与可调整利率的原理可以沿用，具体中国合同及政策适用需另核实，不能用新发放利率替代全部存量月供。

## 9. 真实资料带读：2024年销售额为什么比销售面积降得更多

国家统计局2025年1月17日发布的[2024年房地产报告](https://www.stats.gov.cn/sj/zxfb/202501/t20250117_1958328.html)中，新建商品房销售面积为97,385万平方米，同比下降12.9%；销售额96,750亿元，下降17.1%；开发投资下降10.6%。这是历史发布版本，不是对当前市场的描述。

第一步，确认“新建商品房”不限于住宅，而且这里是全年累计。

第二步，用金额除以面积得到当年成交均价：

```text
96,750亿元 ÷ 97,385万平方米
= 约0.9935万元/平方米
= 约9,935元/平方米
```

第三步，用已公布且经过舍入的增速，近似推算成交均价变化：

```text
(1−17.1%) ÷ (1−12.9%) − 1 ≈ −4.82%
```

第四步，限定结论：这是销售结构混合后的均价变化估算。城市、物业类型、房屋质量及可比统计范围都会影响它，不能直接宣布“全国同一套住房价格下降4.82%”。

第五步，解释投资：销售与投资同时下降与需求、回款压力相容，但这些汇总数不能单独识别原因。还需要资金来源、项目阶段、库存分布和企业状况。同比幅度接近或不同，都不等于一对一的因果系数。

2. 新开工下降、竣工上升，提出一条与中国项目资金安排相容的机制，并指定核查资料。
3. 竣工未售20、在建未售30、已售未交付40，哪个更接近官方待售窗口，哪个对应交付责任？
4. 美国新房销售能发生在建设期吗？为什么“中国预售、美国现房”会误导指标对应？
5. 土地出让收入下降16%，能否断言地方全部财政支出下降16%？
